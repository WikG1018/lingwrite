## 如何跑

- 只做编译检查（无设备）：`cd android && ./gradlew :benchmark:assemble`
- 接真机跑 Macrobenchmark（Pixel 6a 级设备，Android 12 / API 31+）：`cd android && ./gradlew :benchmark:connectedBenchmarkAndroidTest`，具体任务名以 `android/benchmark` 源码注释为准。
- Baseline Profile 生成器 `BaselineProfileGenerator` 同样需要真机；产物 `baseline-prof.txt` 目前尚未提交入库。

## CI

当前 CI 不门禁性能：没有 emulator / benchmark job，benchmark 结果不阻塞 PR，也没有历史趋势留存。阈值与数据补齐后，再把明确的基准写进 CI 或发布检查清单。
