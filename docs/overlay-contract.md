# 弹层与导航的公共约定（v0.2.6）

所有 `LingSheet` 和 `LingConfirm` 注册到主题/应用的持久 `LingOverlayRoot`。调用处可以用条件状态表示关闭，宿主在退出完成后移除内容。按钮关闭、返回、遮罩和拖动共用退出生命周期；关闭中的按钮不能再次触发动作。嵌套确认临时隐藏父层但保留草稿，取消后恢复父层。真正离开页面时销毁父层，不恢复已离开的表单。

普通菜单和表单默认 `SheetLayout.Scroll`，标题固定、内容可滚动。内容本身已经具有一个垂直滚动容器或 Lazy 列表时明确使用 `Viewport`；不要给普通不滚动表单误加 Viewport，也不要嵌套两个无高度约束的垂直滚动容器。弹层最大宽 640dp、圆角 28dp，统一按状态栏、键盘和导航栏约束最大内容高度。创建/保存等按钮以最小高度代替固定高度，允许大字号增高。

确认框使用统一淡入和轻缩放、圆角 24dp、最大宽 560dp、公共遮罩和 150ms 退出。应用减少动画设置取消其缩放。底部弹层的拖动/位移仍使用 Material 组件本身的动画规范，系统动画比例为零时遵从系统禁用动画；并非所有组件都由应用的自定义 token 驱动。

根导航负责设置子页的进入/退出，设置卡片不再重复逐个进入。`Motion.Emphasized` 是完整的两段路径 `(0,0)…(.167,.4)…(1,1)`，按 x 反求参数后求 y，不能把时间直接当贝塞尔参数，也不能在 .5 把第二段重新从零开始。该曲线由单调性、端点、连接和一万点采样回归保护。

侧边便签抽屉的遮罩固定，只移动抽屉面板；提示层属于编辑内容，不放到根节点覆盖状态栏或抽屉。指南继续入口占据独立布局行，不浮在稿件/资料上方。隐藏但保留的平板面板不能抢系统返回；窄详情依据自身容器宽度处理返回，保存章节计划成功后才回列表。

人工验收需保留实际录屏并查看中间帧，静态截图只能说明布局。交互需覆盖打开、输入、保存、取消、系统返回、重开及键盘可达，不能用“页面能渲染”代替。参见 [补丁验收记录](author-acceptance-v0.2.6.md)。
