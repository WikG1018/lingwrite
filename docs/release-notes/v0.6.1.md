# LingWrite v0.6.1（versionCode 19）

> 这是 v0.3.0 之后的第一个正式安装包。v0.4.0、v0.5.0、v0.6.0 只在仓库里升了版本号，没有发过 APK，所以这份说明把 v0.4 到 v0.6 的变化都写在这里，另外加上 2026-10-18 代码审查的修复。

## 新增（v0.4 – v0.6）

- **导入旧稿**：支持 TXT、Markdown 和 DOCX。能识别 UTF-8 和 GB18030 编码，按卷、章标题自动拆分，没有标题时按长度拆分。写入前可以先预览。
- **导出与发布前检查**：
  - 导出支持模板，大文件流式写出，也可以单独复制一章。
  - 发布前检查会看标题、字数、标点、自定义风险词和 AI 标记，结果可以导出成报告。
- **专注模式**：打字机式滚动，带计时和目标进度，没达到目标就退出时会先确认。
- **编辑器速查**：在编辑器里直接查设定、伏笔、前情摘要，也能全文搜索。
- **追读数据复盘**：
  - 可以手动录入，也可以从平台后台复制表格粘贴导入（中文、英文、日文表头都能识别）。
  - 显示完读率曲线，并做掉点诊断。
- **大纲与正文同步**：AI 根据正文起草章纲的修改，先给你看差异，确认后才写入。改动有快照，可以撤销。卷的计划章数和实际章数会对照显示。
- **一致性检查**：新增地点、物品、称谓、信息差四类；新增按章节排列的事件轴。
- **AI 使用体检**：统计 AI 标记段落的占比和采纳率，可以导出报告。
- **听稿**：用系统自带的 TTS 朗读。
- **写作流程**：按写前、写中、写后三步协助写一章；伏笔回收日历。
- **系列共享设定**：多本书可以共用一套设定卡。系列卡要复制到某本书里，才会参与这本书的一致性检查。

## 本版修复（2026-10-18 审查）

- **升级保护**：
  - 升级前的原始库快照改到后台线程生成，先写临时文件再改名，启动时不再卡住。
  - 快照按版本号的数字大小排序，保留最近 2 份（以前按字符串排序，v10 会排在 v9 前面）。
  - 从数据页导出快照时会清空 API Key 的密文。
- **追读**：带 % 的小数不再被放大 100 倍（例如 0.8% 以前会显示成 80%）。
- **听稿**：
  - 分段朗读时，只有最后一段读完才算结束。
  - 朗读语言按作品语言选择。
  - 被其他 App 抢走音频焦点时自动停止。
- **系列**：
  - 加入系列后，列表立刻刷新。
  - 复制系列卡到本书时检查重名，追加「系列来源」字段，并带上卡片之间的关系。
  - 新增：把书移出系列、给系列改名、编辑和删除共享卡。
  - 合并导入备份时，同一个系列不会重复生成。
- **专注模式**：
  - 计时不再导致整个编辑器每秒重组。
  - 旋转屏幕或切换主题后，计时不会归零。
  - 按系统返回键也会走「未达标确认」。
- **大纲同步**：
  - 写入时只合并有差异的字段，不会覆盖你刚改过的内容。
  - AI 返回空备注时，保留你原来的备注。
  - 撤销本身也可以再撤销。
- **编辑器**：恢复章节的操作放进同一个事务；连续两次点「采纳」不会写入两次。
- **导入**：
  - Markdown 里的 `## 第一卷` 能识别成卷。
  - 文件开头的 `# 书名` 会作为书名，不再被当成一章。
- **多语言**：发布前检查、导入、备份、写作流程、AI 体检和系列页面的文案，在英文和日文界面下不再显示中文。章号会按界面语言显示。
- **界面与动效**：
  - 9 个新页面都按动效规范补上了：区块依次进入、列表增删动画、加载超过 150 ms 才显示骨架屏、曲线和进度条生长。
  - AI 状态统一用思考行、候选卡和错误卡（错误卡上可以重试或换模型）。

## 兼容与升级

- 版本：`versionCode 19`，`versionName 0.6.1`。
- **数据库 8 → 10**：都是显式迁移，不会删除数据。
  - 8→9：新增 `read_metrics`、`chapter_plan_versions` 两张表，`chapter_plans` 加 `storyTime` 列。
  - 9→10：新增 `series`、`series_lore` 两张表，`books` 加可空的 `seriesId` 列（外键，删除系列时置空）。
- 升级前 App 会在本机自动保存一份原始数据库快照，可以在「设置 › 数据」里导出。导出的快照不含 API Key。
- 签名密钥和 v0.3.0 相同，可以直接覆盖安装。
- 安装要求：Android 12（API 31）或更高版本。
- 建议覆盖安装前，先在「设置 › 数据 › 备份与恢复」导出一份整库备份。

## 校验

- 下载后请先核对 SHA-256 和签名证书指纹（见本页下方由发布流程追加的 `SHA-256` 与证书行）。对不上就不要安装。
