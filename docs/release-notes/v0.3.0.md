# LingWrite v0.3.0（versionCode 15）

## 新增

- **界面多语言**：简体中文（默认）、English、繁體中文、日本語。
- **语言设置**：「设置 › 外观 › 界面语言」可跟随系统或手动指定；Android 13 及以上同时接入系统的「应用语言」。
- **卷 / 章编号按界面语言显示**：第二卷 / Volume 2 / 第2巻，第 118 章 / Chapter 118 / 第118章。导出的文本仍为中文网文格式。
- **AI 输出语言**：设置里的「AI 输出语言」默认跟随作品语言，也可以手动指定；AI 提示词本身保持中文。

## 兼容与升级

- 版本：`versionCode 15`；数据库版本仍为 8，**无数据库迁移**。
- 签名密钥与 v0.2.x 相同，可直接覆盖安装。
- 安装要求：Android 12（API 31）或更高版本。
- 从 v0.2.x 覆盖升级前，建议先在「设置 › 数据 › 备份与恢复」导出一份整库备份，以防万一。

## 校验

- 下载后请先核对 SHA-256 和签名证书指纹（见本页下方由发布流程追加的 `SHA-256` 与证书行），不一致就不要安装。
