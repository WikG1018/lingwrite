# v0.2.6 手机界面与交互补丁验收

基线是 v0.2.5 / `c7c8ff1381a807cb2c40dc359b188a49a6f7c63d`。本次使用独立 Android 35 x86_64 模拟器与合成稿件，未读取真实稿件、未调用付费或真实 AI 服务。用户提供的截图仅在本地私有目录查看，不进入仓库或发布附件。

## 可复现问题及修复

| 问题 | 复现及影响 | 修复与验收 |
|---|---|---|
| 页面动画过半倒退 | 原曲线在 t=.5 时为 .4，t=.500001 时跳回约 .000005；关于页还有卡片分批进入，通知/更新页等待偏好流时先空白 | 按完整两段贝塞尔路径反求 x，检查一万采样点单调和连接处连续；设置子页共用导航过渡和稳定首帧 |
| 新建书键盘遮住创建 | 320×640dp、字号 1.5，输入标题后按钮在键盘下面，弹层无法滚动 | 公共弹层统一键盘/安全区约束，普通表单默认滚动；实际打开键盘、填写、点击创建并核对数据库 |
| 菜单按钮关闭瞬间消失 | 调用处把条件置 false，弹层立刻卸载，而遮罩/下滑则先退出动画 | 持久 OverlayHost 保留关闭层到退出完成；按钮、遮罩、系统返回、拖动四条路径及嵌套确认返回均验证 |
| 提示遮状态栏和便签抽屉 | 编辑页根节点的兄弟提示层落在状态栏并盖住抽屉标题 | 提示放入编辑内容区域；抽屉独立遮罩与面板，状态栏/导航栏留白，系统返回先关闭抽屉 |
| 窄屏标题与控件挤压 | 大字号下标题被挤没、今日字数和 AI 按钮截断；设置右侧值把说明压成多行碎片 | 手机标题与动作分行，今日字数独立区域，按钮最小高度；窄设置行的值放到标题下 |
| 空书架的示例入口被挡 | 320dp 大字号下空态内已有建书按钮，第二个浮动按钮盖住示例入口 | 空书架不重复放浮动按钮；实际点击示例入口，核对创建 8 章及非空正文 |
| 章节计划系统返回不保存 | 手动修改核心事件后，父级返回处理直接清选择，跳过子级保存 | 按实际可用面板宽度处理返回，隐藏面板不抢事件，保存成功后返回；核对事件和原备注同时保留 |
| 老用户看不到指南、浮动指导遮内容 | 旧用户默认关闭指南；收起后的浮动按钮覆盖设定库说明 | 升级一次邀请、可跳过并记录版本；独立布局行继续指导，设置可重开，编辑器更多菜单可打开当前章写作指南 |
| 校对标记不刷新 | 可变列表身份不变时 remember(proof) 缓存旧范围；正文变化也不重新定位 | 根据当前正文与可观察列表重新计算位置；原校对定位单元测试保留 |

## 验收口径

冻结版本回归结果：45 个 JVM/Compose 测试类、206 项测试，零失败/错误/跳过；lint 零错误、39 条警告。设备 runner 23 项通过（手机专项 10 项、原手机 7 项、平板 6 项）。指南原生录屏之外，还读取专用 debug 应用的合成数据库，确认 `QA_GUIDE_SAVED_026` 已写入章纲；不读取真实用户数据。

JVM/Compose 回归、设备按钮操作、页面渲染和人工录像检查分别记录。页面渲染通过不等于每个按钮或异常路径通过。v0.2.5 的全功能矩阵仍用于未改变能力的范围说明；本补丁不把旧矩阵的部分覆盖改称完整覆盖。

`OverlayQualityDeviceTest` 的设备按钮链路覆盖：键盘建书，空书架示例入口创建 8 章，20 项菜单滚到末项与四种关闭，嵌套确认取消回父层，模式提示与便签层级/返回，系统返回保存章纲，老用户邀请跳过，人物创建/取消编辑/重开，伏笔登记/回收保存，编辑器指南打开真实章纲与再次打开。

`AuthorDeviceTest` 验证中文正文修订/撤销重做/保存、删除确认取消与恢复、迟到 AI 结果拒绝、指南跳过、手工章纲字段保留及注册入口渲染。`TabletDeviceTest` 验证宽屏→竖屏→窄分屏保留正文、选择、合成输入、撤销和受控 AI 协程；真实章纲保存、设定/伏笔/总纲的列表详情、指南真实入口与目录顺序/续章。尺寸为 1400×900、800×1100、720×900、480×900dp；字体 1.0/1.5。手机专项为 320×640dp、字体 1.5、系统动画比例 1。

实际 ADB 录像 `after-three-settings.mp4` 包含关于、通知、应用更新的进入与返回；人工检查原生录屏中间帧确认连续过渡，未以静态设计稿替代。键盘建书前后、模式提示与抽屉层级、计划保存、指南邀请均有合成数据截图。发布附件只打包明确选择的合成证据。

`after-overlay-dismiss.mp4` 记录按钮、遮罩、返回与拖动的退出；它录于最后一项空书架遮挡修复之前，空态布局以最终 `empty-shelf-unobstructed-sample-entry.png` 为准。`after-guide-real-chain.mp4` 是实际原生手机“章纲→保存→返回编辑→更多重看→跳过”链路。人工已查看这两段录像的中间帧和结束页面。

复跑：在独立测试设备运行 `adb -s <设备> shell am instrument -w -e class com.lingwrite.app.OverlayQualityDeviceTest,com.lingwrite.app.AuthorDeviceTest,com.lingwrite.app.TabletDeviceTest com.lingwrite.app.debug.test/androidx.test.runner.AndroidJUnitRunner`。测试会改模拟器尺寸、字号与动画参数，不能在真实用户手机上运行。构建检查为 `gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest assembleRelease`。
