# 界面多语言

支持：简体中文（默认，`values/`）、English（`values-en/`）、繁體中文（`values-zh-rTW/`）、日本語（`values-ja/`）。

- **文案来源**：`tools/i18n/extracted.json` 是简体中文原文（键名 = 所在文件前缀 + 序号），`tools/i18n/tr-<lang>.json` 是各语言译文。改完运行 `python3 tools/i18n/gen.py`，会重新生成 `values*/strings.xml` 和 `i18n/I18nMap.kt`。不要手改生成的文件。
- **取字符串**：界面里用 `tr(R.string.xxx, args…)`（Composable 和普通函数都能用）。数据层存的中文标签或内部 id，显示时用 `trText(中文原文)`。
- **AI 提示词保持中文**：提示词片段用 `trZh(...)`，永远取简体中文资源；这些键没有译文，在默认资源里标了 `translatable="false"`。AI 用什么语言回答由设置里的「AI 输出语言」决定（默认按作品的书名、简介和最近几章判断）。
- **卷 / 章编号**：`VolumeLabel` / `ChapterLabel` 按界面语言输出：第二卷 / Volume 2 / 第2巻；第 118 章 / Chapter 118 / 第118章。导出格式仍是中文网文格式。
- **语言设置**：设置 › 外观 › 界面语言（跟随系统或手动）。Android 13+ 走系统 per-app language（`res/xml/locales_config.xml`），Android 12 存在本地并在 `attachBaseContext` 套用。
- **检查**：`LocaleShotTest` 在 en / ja / zh-TW 下各拍主界面截图（输出到 `<shotDir>-<lang>/`），用来人工看溢出和截断；单测默认语言是 zh-CN（`src/test/resources/robolectric.properties`）。
- 繁体译文由 OpenCC（s2twp）转换后人工抽查，欢迎母语者提 PR 修正。
