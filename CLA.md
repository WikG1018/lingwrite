1. **定义**。「贡献」是指你有意提交给本项目、供纳入的任何作品，包括代码、文档、翻译、设计稿和图片，以及对它们的修改。仅在 Issue、讨论区中发表、且未明确表示希望纳入的意见，不属于贡献。
2. **版权保留**。你保留贡献的全部版权。本协议不转让版权。
3. **版权许可**。你授予维护者及其继任者一项永久、全球、非独占、免费、不可撤销的许可：可以复制、修改、公开展示、表演、再许可和分发你的贡献及其衍生作品，**授权方式不限于 AGPL-3.0，也包括专有授权或商业授权**，并可将上述权利再授予第三方。维护者可以将本协议下的权利转让给项目的继任维护者或权利承继人。
4. **专利许可**。如果你的贡献涉及你拥有或可授权的专利，你授予维护者及接收本项目软件的人一项永久、全球、非独占、免费、不可撤销的专利许可，范围仅限于你的贡献本身，或贡献与本项目结合使用的情形。如果任何人就本项目提起专利侵权诉讼，主张你的贡献或本项目侵犯其专利，则其依本条获得的专利许可自起诉之日起终止。
5. **回馈承诺**。维护者承诺：只要本项目继续以开源方式发布，你的贡献就会同时以 AGPL-3.0（或更新版本的 OSI 认可协议）提供。
6. **人身权利**。在适用法律允许的范围内，你同意不就维护者依本协议对贡献进行的合理修改、翻译和整合主张保护作品完整权；维护者会在项目的贡献者名单或提交历史中保留你的署名。
7. **你的保证**。你保证：(a) 贡献是你的原创作品，或者你有权依本协议提交；(b) 如果你的雇主或其他方对你的作品享有权利，你已获得其提交许可；(c) 你会在贡献中注明其中任何第三方作品及其授权；(d) 你已年满 18 周岁，或已取得监护人同意。如果之后得知上述任何一项不再属实，你会及时通知维护者。
8. **不附带的权利**。本协议不授予你任何商标权，「灵写 / LingWrite」名称和图标的使用见 TRADEMARK.md。维护者没有义务采纳或使用你的贡献。
9. **无担保**。除第 7 条外，贡献按「现状」提供，你不承担任何明示或默示的担保责任。
10. **签署**。签署方式是在 PR 中按 CLA 机器人的提示回复同意；在机器人启用前，可在 PR 描述中写明「我已阅读并同意 CLA.md（版本 0.2）」。签署与你提交 PR 的 GitHub 账号绑定，适用于你此后的所有贡献，除非你书面通知维护者撤回对未来贡献的适用；撤回不影响已提交的贡献。
11. **适用法律与可分割性**。本协议适用中华人民共和国法律（不含冲突法规则）。如有任何条款被认定无效，不影响其余条款的效力。
