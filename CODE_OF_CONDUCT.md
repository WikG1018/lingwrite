# 行为准则 / Code of Conduct

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)（[简体中文](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/) · [English](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) · [日本語](https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/)）。

**简要来说**：对人友善，就事论事；不骚扰、不人身攻击、不发歧视言论，也不擅自公开他人的私人信息。在 Issue、PR、讨论区以及代表项目的任何场合都适用。

**举报**：请通过 GitHub 私信维护者 @WikG1018，或使用 GitHub 的「Report content」功能。维护者会保密处理，并视情况给出警告、临时或永久禁止参与等处理。

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind and stick to the issue. Harassment, personal attacks, discriminatory language and publishing other people's private information are not tolerated. To report a problem, message the maintainer @WikG1018 privately on GitHub or use GitHub's "Report content". Reports are handled in confidence.
